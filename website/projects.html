Campus Network Monitor

A student-built dashboard for visualizing network health and activity. The system aggregates SNMP statistics, measures packet transmission delays across campus buildings, and provides an intuitive web interface for visualizing network throughput.

Cybersecurity In Development

Secure Attendance System

A prototype attendance platform designed with authentication and access control in mind. Incorporates tamper-resistant time-based token generation and cryptographic validation to prevent unauthorized check-in spoofing.

Tech Stack: Node.js, WebCrypto API, SQLite, CSS Modules
Team Size: 5 Contributors
Deployment: Staging Sandbox
Security Audit: In Progress Learn More
Artificial Intelligence Research Prototype

AI Threat Detector

A research prototype exploring machine-learning-assisted anomaly detection. Analyzes sampled flow records using lightweight unsupervised clustering algorithms to identify port sweeps, unauthorized tunnels, and outbound exfiltration patterns.

Tech Stack: Python, Scikit-learn, Pandas, PyTorch
Team Size: 3 Contributors
Deployment: Cyber Research Sandbox
